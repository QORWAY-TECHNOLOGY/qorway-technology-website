# QORWAY Technology Website

Official public website for **QORWAY Technology**.

QORWAY is a sovereign Decision Intelligence infrastructure for Europe.

This repository contains the public website only. It is intentionally separated from:

- `qorway_technology` — public documentation and institutional architecture repository
- `qorway-core-private` — private implementation, IP, internal specifications, prompts, scoring, causal rules, and production contracts

## Stack

- Next.js App Router
- TypeScript strict mode
- Tailwind CSS
- Static export compatible with GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run lint
npm run build
```

The static export is generated by Next.js and can be deployed to GitHub Pages or another static host.

## Design Direction

The visual system must express:

- sovereignty by design
- causality
- constraint-native execution
- auditability by default

Primary identity:

- near-black background
- cream / sand typography
- terracotta signal accent
- architectural, institutional, European technology aesthetic

## Public / Private Boundary

This website may explain public-safe architecture concepts.

It must not expose:

- production schemas
- internal prompts
- causal rule libraries
- scoring models
- PolicyCore implementation rules
- PulseFlow production contracts
- GreenCore routing logic
- private Domain Pack internals
- tenant-specific data
- proprietary execution logic
